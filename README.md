
# FoodGo - Delivery

Projeto de aplicativo de delivery desenvolvido como atividade acadêmica.

## Tecnologias utilizadas
- React
- JavaScript
- Vite
- CSS

## Como executar o projeto

1. Instale as dependências:
   npm install

2. Execute o projeto:
   npm run dev

## Publicação
Projeto publicado na plataforma Vercel.
